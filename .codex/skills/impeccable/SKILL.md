# Visual refinement

Use this skill for a final visual pass. Preserve the project's brand colors, type choices, imagery, and component language while improving rhythm and consistency.

Check alignment, spacing scale, line lengths, optical balance, contrast, border and shadow restraint, responsive composition, and states. Remove visual noise instead of adding effects. Avoid excessive rounded cards, glow effects, gradients, floating decoration, and animations that do not communicate something. Prefer a small number of intentional refinements that make the interface feel authored.
