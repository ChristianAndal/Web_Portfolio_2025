# UI/UX workflow

Use this skill when making UX or interaction decisions. Inspect existing navigation and component behavior first, then preserve familiar patterns unless there is a clear usability problem.

Prioritize semantic HTML, visible focus, keyboard access, readable contrast, touch-friendly controls, predictable responsive layouts, and content hierarchy. Test 320px mobile, 768px tablet, 1024px laptop, 1280px desktop, and 1440px large desktop behavior. Check text wrapping, overflow, modal focus, hover/focus states, and reduced-motion behavior.

Do not add interaction merely for novelty. Every transition should clarify state or hierarchy and must not prevent access to content.
