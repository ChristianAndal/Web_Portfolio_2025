# Frontend design

Use this skill for page composition, landing pages, sections, responsive UI, and component composition.

Before editing, inspect the current framework, UI library, tokens, assets, typography, breakpoints, and reusable markup. Extend the existing visual language instead of replacing it. Establish a clear hierarchy, useful whitespace, semantic structure, and responsive behavior from 320px upward.

Prefer small reusable patterns over one-off markup. Keep branded public-facing UI distinct from default library styling where appropriate, but do not replace the project's UI framework. Avoid generic AI patterns such as oversized gradient headlines, random purple gradients, excessive glassmorphism, and decoration without purpose.

For animation, use the project's shared GSAP utilities and keep motion subordinate to content and interaction.
